Research

Current work · IES, Academia Sinica

Distributed acoustic sensing for seismic monitoring

DAS turns a fiber optic cable into a dense line of seismic sensors. I am developing monitoring with DAS records and linking it to the stations of regional seismic networks, so that fiber and conventional stations contribute to one catalog.

  • Phase picking on DAS records
  • Event location
  • Integration with regional seismic networks
Phase picking & detection

Deep learning pickers for continuous data

ARRU Phase Picker picks P and S arrivals with an attention recurrent residual U-Net. RED-PAN detects earthquakes and picks phases in real time with a multitask attention network.

ARRU code RED-PAN code
Autonomous networks

From phase probabilities to located events

Backprojecting phase time functions predicted by deep learning detects and locates earthquakes directly on continuous recordings, a step toward seismic networks that run without manual picking.

Backprojection code
Slope failure

Rockfalls and earthquakes in one model

RockNet detects and associates rockfalls and earthquakes through multitask and transfer learning, for seismic monitoring of slope hazards.

RockNet code
Seismotectonics & early warning

Earthquake sequences in Taiwan

A deep learning catalog of the 2025 M6.4 Dapu sequence resolves its seismogenic structure. Related work covers crustal tomography of west-central Taiwan, and hypocenter location and magnitude estimation for earthquake early warning.
