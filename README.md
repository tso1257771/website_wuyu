# website_wuyu

Personal academic website of Wu-Yu Liao, postdoctoral researcher at the Institute of Earth Sciences, Academia Sinica.

Live site: https://tso1257771.github.io/website_wuyu/

- `index.html`: the whole site (HTML, CSS, and JS in one file, no build step)
- `design-system/`: design tokens generated with [ui-ux-pro-max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)

To update, edit `index.html` and push to `main`. GitHub Pages redeploys in about a minute.
